# Checklist

> 验收标准依据用户输入"最终验收标准"。逐项核对代码与行为，全部通过才可宣布完成。

## 第一阶段：生产安全与鉴权
- [x] 密码使用可靠哈希（bcrypt）存储与校验
- [x] token 带明确过期时间；过期 token 被拒绝并清理
- [x] 登出可撤销 token
- [x] 登录失败不泄露用户是否存在（一致 401 文案）
- [x] 连续失败登录有速率限制
- [x] 演示账号快捷登录仅限 `APP_DEMO_MODE=true`（开发/演示）
- [x] 前端 401 清除 token/用户/权限状态、避免重复弹错、保存返回地址、跳转登录、登录后回原页面
- [x] 所有后端路由有认证/角色/资源级权限校验，权限测试覆盖登录成败/token 过期撤销/RBAC/资源级权限

## 第二阶段：API、数据一致性与错误恢复
- [x] 不存在空的异常捕获和静默失败
- [x] 写操作统一 pending/success/error 状态，服务端确认后才提示成功，乐观更新回滚，防重复提交
- [x] 供应商定标不覆盖其他物料选择（完整映射或增量 PATCH），有多物料选择/重复修改回归测试
- [x] 询价/报价有并发控制（version/updatedAt），冲突返回 409，前端展示冲突并提供重新加载/重新应用
- [x] 询价编号服务端生成，DB 唯一约束，并发碰撞事务内重试，不依赖客户端时间戳末几位
- [x] Axios 仅 GET/HEAD 有限重试；写请求不盲目重试；确需重试用 idempotency key；有超时/取消/重复合并
- [x] 后端错误统一转为前端可消费错误模型；本地数据不长期伪装成已保存

## 第三阶段：加载态、空状态、保存态和失败态
- [x] 核心页面建立统一状态模型（idle/loading/refreshing/success/empty/saving/error/offline）
- [x] Dashboard 空数据不永久显示 Skeleton；Skeleton 仅用于首次加载
- [x] 图表/表格/卡片/详情页统一空状态与错误状态组件，错误状态提供"重新加载"
- [x] 评论保存前 trim、显示"正在保存/已保存/保存失败"、服务端确认后提示成功、避免旧请求覆盖新内容
- [x] PDF/Excel 导出有导出中状态、防重复点击、成功/失败提示、大数据量保护

## 第四阶段：报价对比与核心采购体验
- [x] 清理不合理的 `useEffect` 依赖与 lint 禁用
- [x] 询价/报价刷新或路由切换不覆盖未提交选择与评论
- [x] 区分供应商选择/单项推荐/整体推荐/人工决定；选择非推荐供应商时可填原因（不强制普通场景）
- [x] 对异常/缺失/超预算/交期/付款风险给出可解释提示
- [x] 仅在真实性能分析证明有收益时使用 memo/useMemo/useCallback；必要时分页/虚拟滚动/分段渲染
- [x] 修复数组索引 key、陈旧闭包、重复计算问题

## 第五阶段：列表、筛选与移动端体验
- [x] 自定义列设置（列显示/隐藏、列宽、固定列、密度、排序、批量选择、批量操作、恢复默认），不依赖不存在的 `columnSetting`
- [x] 筛选/排序/分页/搜索持久化并可恢复
- [x] "清除所有筛选" + 展示当前生效条件
- [x] 375/768/桌面宽度下关键按钮不越界、筛选可收起、表格可读、固定操作区不遮挡、弹窗/抽屉完整可操作

## 第六阶段：无障碍与键盘操作
- [x] 语义化按钮/链接/标题/表单标签/表格；可点击 `div` 改造为按钮
- [x] 键盘可操作、清晰焦点、弹窗焦点管理、关闭后焦点返回触发元素
- [x] 图标/状态/图表/异步状态加 ARIA 辅助文本；对比度不依赖单一颜色
- [x] axe 无障碍检查覆盖核心页面，无严重级问题

## 第七阶段：AI 服务真实化和可降级设计
- [x] 抽象 `AIBackend`/`LocalRuleBackend`/`RemoteAIBackend`，环境变量选择后端
- [x] 界面显示当前模式（本地规则/远程 AI/降级/AI 不可用）；不通过固定延时制造"思考"假象
- [x] 远程调用带超时/取消/错误/限流/敏感信息过滤/可控日志/用户确认
- [x] AI 输出结构校验，不直接信任自由文本；最终定标保留人工确认
- [x] 本地规则与远程后端分别有测试

## 第八阶段：后端工程化与可观测性
- [x] 引入 Alembic 并生成可验证的首个迁移
- [x] 结构化日志 + request ID；前端错误/后端日志/Sentry 通过 request ID 关联
- [x] 区分用户输入/权限/数据冲突/服务不可用/未知系统错误；健康检查与就绪检查
- [x] 日志不记录密码/完整 token/敏感采购数据；事务边界保证不产生半完成数据

## 第九阶段：自动化测试与 CI 门禁
- [x] 前端测试覆盖 API client/401/Store 异常回滚/并发/Dashboard 空态/评论保存/多物料定标/报价异常/中英切换/移动端
- [x] 后端 pytest 覆盖登录成败/token 过期撤销/RBAC/资源级权限/状态流转/唯一编号/并发冲突/事务回滚/非法输入/多物料定标完整性
- [x] Playwright 增加真实后端模式，覆盖完整主流程并验证刷新后数据正确
- [x] CI 实际执行 npm ci + ESLint + tsc + Vitest + build + pytest + Playwright 真实后端流程；失败输出日志与截图/trace
- [x] 后端 import smoke test 不替代 pytest
- [x] 生成 `.env.example`；README/部署/迁移/测试说明与环境变量示例与实际代码一致
