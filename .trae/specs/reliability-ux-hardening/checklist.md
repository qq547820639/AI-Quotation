# Checklist

> 验收标准依据用户输入"十五、最终验收标准"。逐项核对代码与行为，全部通过才可宣布完成。

## 第一批：可靠性和数据一致性
- [x] 写操作失败不会显示成功（供应商/询价/报价/评审意见）
- [x] 后端失败不会造成前端永久错误状态（本地状态回滚、输入保留）
- [x] 非幂等请求不会被无保护地自动重试（POST/PUT/PATCH/DELETE 5xx 不自动重发）
- [x] 幂等请求（GET/HEAD）可自动重试
- [x] 统一错误对象存在且被使用（code/message/fieldErrors/status/retryable）
- [x] 401 清理会话并记录回跳地址，登录后跳回原页面
- [x] 403/409/网络/超时/服务不可用使用不同提示
- [x] 所有错误文案进入 i18n，无硬编码中文错误提示
- [x] 每写操作有独立 loading 与防重复提交；提交期间按钮禁用
- [x] API Client 重试策略测试通过

## 第二批：权限和批量操作
- [x] 批量操作使用语义化方法，不再用 toggle 实现明确业务动作
- [x] 批量操作前展示选中/可执行/不可执行数量与原因
- [x] 批量操作后逐条反馈成功/失败与原因；部分成功不提示"全部成功"
- [x] 批量停用不反向启用已停用记录
- [x] 后端拒绝操作时前端不提前永久改变状态
- [x] 操作完成后正确刷新数据与选中状态；高风险批量二次确认
- [x] 前端权限定义与后端一致；后端再次校验权限
- [x] 无权限按钮/页面明确提示；直接访问无权限 URL 正确处理
- [x] 403 不改变前端本地状态
- [x] 演示认证与正式认证解耦，预留 password/SSO/token-refresh 接口层
- [x] 权限矩阵测试通过

## 第三批：核心体验
- [x] 评审意见 debounce 保存，显示"保存中/已保存/保存失败"状态
- [x] 页面离开前检测未保存内容；保存失败保留输入
- [x] 对比组件使用 memo/useMemo/useCallback，输入不拖垮大表
- [x] 评分展示分项明细与权重；AI/规则建议展示推荐依据并允许调整
- [x] 询价/供应商列表支持列设置、密度、固定列、筛选/排序/分页/列配置持久化
- [x] 提供"待我处理"快捷视图、重置默认、显示当前筛选、一键清空、导出当前结果
- [x] 批量操作栏固定、可退出选择；危险操作与普通操作区分
- [x] 移动端卡片单主操作 + "更多"菜单；筛选用 Drawer/Bottom Sheet；表单按钮不被遮挡
- [x] 中英文切换后错误/提示/表格/日志/AI 文案均国际化；金额/日期/数字格式与语言一致

## 第四批：测试和交付
- [x] 核心询价流程存在真实 E2E 测试（登录→创建→发送→供应商报价→对比→评审→审批→定标→持久化）
- [x] E2E 关键步骤缺失时失败而非跳过
- [x] E2E 覆盖异常场景（超时/网络/500/401/403/重复点击/部分批量失败/表单校验/冲突/刷新/返回/保存失败重试/不同权限）
- [x] 后端 API 集成测试、权限矩阵测试、事务与状态流转测试通过
- [x] Store 异常处理测试通过；API Client 重试测试通过
- [x] CI 包含前端 lint/typecheck/单测/构建、后端测试、Docker 构建/Compose/健康检查、Playwright E2E
- [x] Docker 端口/环境变量/健康检查/数据持久化/初始化脚本可重复执行，与部署文档一致
